Subtitle bridge

Sign in to see and change the settings.

Forgot it? Run python subcfg/subcfg.py reset-password --dir <your config folder> on the machine that holds the config folder, then open this page again to choose a new one.

First time here. Choose a password for the admin account. Anyone who knows it can change the settings, so pick a good one.

At least 8 characters, and nothing like "password" or "12345678".
This page is only offered to computers on your local network, and only until a password is set.

The config folder is read-only.

The password is stored in the config folder, so the bridge needs to be able to write there. Mount the folder read-write into the bridge (remove :ro, for example ../config:/config), restart it and reload this page.
